Yes, but not from the barcode alone. There are ways to detect it automatically, depending on your network equipment.

Here are the options, from best to simplest:

Option 1: Use a Managed Network Switch (Recommended)

If your LAN cables connect to a managed switch (Cisco, TP-Link JetStream, MikroTik, Ubiquiti, etc.), the switch already knows which device is connected to each port.

The flow would be:

Laptop L-001 is connected to LAN cable LN-005.
LN-005 is permanently connected to Switch Port 12.
The managed switch detects the laptop's MAC address on Port 12.
Your software looks up:
MAC Address → Laptop L-001
Port 12 → LAN Cable LN-005
Result:

Laptop L-001 is connected to LAN Cable LN-005.

No manual scanning is required.

Option 2: Use the Laptop's MAC Address

Every laptop has a unique network identifier called a MAC address.

Store this in your database:

Laptop      Barcode     MAC Address
L-001 LAP001      3C:52:82:AA:12:45

Then store:

LAN Cable   Switch Port
LN-005      Port 12

When the laptop is plugged in:

Switch reports MAC 3C:52:82:AA:12:45 on Port 12
Database matches:
MAC → L-001
Port 12 → LN-005

Automatically mapped.

Option 3: Small Software Agent

Install a small program on each laptop that reports:

Laptop ID
MAC address
IP address
Connection status

Your server periodically checks the network and updates the mapping automatically.

Can this work with an unmanaged switch?

No. An unmanaged switch does not expose which MAC address is connected to which physical port, so there's no reliable way to map a laptop to a specific LAN cable automatically.

Since you run a digital library

I would recommend this setup:

Barcode every laptop.
Barcode every LAN cable.
Use a managed switch.
Store:
Laptop Barcode
Laptop MAC Address
LAN Cable Barcode

Build a small dashboard that polls the switch every few seconds or minutes.

No one needs to scan the cable or update the record manually.
